
# Last Breathe – Survival Game

**Last Breathe** — это 2D-игра на выживание, где игрок оказывается на необитаемом острове после крушения вертолёта. Основная цель — выжить, исследуя мир, добывая ресурсы, крафтя оружие и инструменты, сражаясь с дикими животными и находя путь к спасению.

## Быстрый старт

### Предварительные требования
- Python 3.8+
- Pygame

### Запуск проекта

#### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/last-breathe.git
cd last-breathe
```

#### 2. Установка зависимостей
```bash
pip install pygame
```

#### 3. Запуск игры

## Функциональные возможности

### Для игрока
- ✅ Динамический мир с днём/ночью и изменением освещения
- ✅ Крафтинг инструментов, оружия и строительных объектов
- ✅ Ближний бой и стрельба (лук, пистолет)
- ✅ Строительство стен, дверей и костров
- ✅ Сохранение и загрузка прогресса

### Для животных (ИИ)
- ✅ **Волки** – агрессивные, атакуют стаей
- ✅ **Медведи** – сильные, не убегают
- ✅ **Олени, кролики** – убегают от хищников
- ✅ **Лисы** – охотятся на кроликов

## Управление

| Клавиша | Действие |
|---------|----------|
| **W A S D** | Перемещение |
| **Shift** | Бег (тратит энергию) |
| **ЛКМ** | Атака / добыча / крафт |
| **I** | Открыть инвентарь |
| **1–5** | Выбрать слот хотбара |
| **E** | Взаимодействие с дверью |
| **B** | Режим строительства |
| **R** | Перезарядка пистолета |
| **F5** | Сохранить игру |
| **ESC** | Главное меню |
| **Колёсико мыши** | Зум камеры |

## API Документация

### Основные игровые системы

#### Управление состоянием игрока
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `update()` | `player.update()` | Обновление голода, жажды, регенерация |
| `move()` | `player.move(keys, structures)` | Перемещение с коллизиями |
| `attack()` | `player.attack(enemies, mouse_pos)` | Атака по врагам |

#### Работа с инвентарём
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `add_item()` | `player.add_item(item_id, amount)` | Добавление предмета |
| `remove_item()` | `player.remove_item(item_id, amount)` | Удаление предмета |
| `use_item()` | `player.use_item(item_id)` | Использование предмета |

## Тестирование

### Запуск тестов (в разработке)
```bash
# Для тестирования боевой системы
python -m game.systems.combat

# Для проверки генерации мира
python -m game.systems.environment
```

### Проверка ключевых сценариев

1. **Пролог и обучение** – запустить новую игру, пройти кат-сцену крушения
2. **Сбор ресурсов** – подойти к дереву/камню, зажать ЛКМ с подходящим инструментом
3. **Крафтинг** – открыть инвентарь (`I`), собрать ресурсы, нажать на рецепт
4. **Бой с волком** – подобрать пистолет, прицелиться и выстрелить
5. **Строительство** – скрафтить `campfire_kit`, нажать `B`, разместить объект
6. **Сохранение/загрузка** – нажать `F5`, перезапустить игру, загрузить сохранение
